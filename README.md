# Bitcoin Custody UK

A crypto portfolio and account platform with a secure backend API and a polished landing/dashboard experience.

## Live URLs

- Frontend: https://franchise23.github.io/quantum-ledger-clone
- Backend API: https://bitcoin-custody-uk.onrender.com

## Local development

1. Start the API:
   npm install
   cd quantum-backend
   npm install
   npm start
2. Open the frontend files directly in a browser or serve them with a local web server.
3. Register a user from the landing page and sign in to access the dashboard.

## Notes

- Registration is handled by the backend API and persists to a JSON file in the backend storage folder while the service is running.
- The dashboard still uses a default portfolio snapshot until real portfolio/account data is connected to your backend or database.
